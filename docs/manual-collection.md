# 수동 수집 화면 · 변경 범위와 운영 연동

## 사용 방법과 진행률 기준

- 상품 화면 상단에 관리자 바로가기. 관리자 화면의 상태는 공개 읽기 전용이며, 자동 예약은 추가하지 않습니다.
- 운영 주소에서 GitHub의 기존 권한 확인 화면으로 연결합니다. 해당 화면에서 저장소 쓰기 권한이 있는 사용자만 `Run workflow → main → all`을 완료할 수 있습니다. 아쿠아픽에서 누르는 링크 자체는 **수집을 시작하지 않습니다**. 게시가 가능한 작업이므로 검증용 클릭은 마지막 GitHub 실행 전에서 멈춥니다.
- 미리보기(local 포함)에서는 실행 링크가 없어 운영 수집을 시작할 수 없습니다. GitHub에 공개된 운영 수동 실행의 읽기 전용 상태만 확인합니다.
- 시작·대기·진행·완료/부분실패·실패·취소를 구분합니다. 백분율은 해당 실행(동일 run ID와 attempt)의 검증된 작업 단계 분모 기준입니다. 판매처·상품의 수집 비율 또는 남은 시간이 아닙니다. 성공 또는 작업이 모두 종료된 부분실패에서만 100%를 표시하며, 단계의 분모가 확인되지 않으면 진행 중 표시만 합니다.
- 브라우저의 공개 API 조회는 GET, 인증 생략, 리퍼러 미전송. 현재 실행 표시 중 90초 간격(최대 30분), 숨겨진 탭은 중단. 상태 다시 확인은 최소 간격 제한을 둡니다. API 제한·실패 상태에서는 마지막 기록을 현재 값으로 표시하지 않습니다.
- 기록의 게시 단계 성공은 새 데이터가 실제로 게시됐다는 증거가 아닙니다. 부분 실패는 게시 단계 성공 및 판매처 실패 보고 단계 실패의 조합입니다.
