4. 판매처 비교: `comparisonIdentity`의 검증 근거와 브랜드/모델/규격/구성(생물은 품종/크기/성별/등급/수량)이 모두 있는 경우 일반적으로 묶는다. 원본의 `comparison_identity`는 게시 투영에서도 보존한다. 현재 자료에는 완전한 구조화 식별자가 없어 검토된 에하임 섭스트라트 프로 단품·동일 내용량 규칙도 사용한다. 5L 두 판매처만 실제 교차 비교가 가능하며 세트·외부여과기·부품·Pro Plus는 제외한다. 가격은 배송 제외 상품금액이며 배송 포함 최저가라고 표현하지 않는다.
5. 최신성: 개별 `observedAt`, 상대 시각/정확한 시각, 재확인 필요 및 최근 24시간/7일 필터를 제공한다. 가격 확인과 재고 상태를 분리한다. 수집은 기존 예산의 최대 1/3을 오래된 상세 관찰 항목에 배정하고 나머지는 재개 가능한 순환을 유지한다. 실패·목록 조회만으로 상품 확인 시각을 바꾸지 않는다. 생물 12시간/용품 24시간 게이트·요청/시간 예산·stock hold·lastgood는 변경하지 않는다. 과거 데이터가 남는 원인은 제한된 순환 예산, 오류 시 마지막 유효값 보존, 일부 오래된 미등록 판매처 항목이다. 전역 검색/클릭 인기도 신호는 없으며 로컬 기록은 서버로 전송하지 않는다.
6. 금액: 희망 수량을 묶음으로 올림하고 실제 구매량·상품금액을 표시한다. 확인된 최소 주문과 배송 정책, 무료배송 경계, 주문/묶음 배송비, 주문/박스 포장비를 계산한다. 정책의 판매처·근거·확인 시점·완전성 중 하나라도 부족하면 배송 포함 합계를 보류한다. 최소 주문 미확인은 별도 안내한다. 판매처 간 주문 조건은 합산하지 않는다.
7. 화면: 상세 필터·근거는 접고 적용 조건은 개별 삭제 가능한 칩으로 표시한다. 상품/옵션/현재 표시 수량 기준을 분리한다. 모바일 카드, 정확한 옵션 링크, 더 보기·URL·뒤로가기와 0건 회복을 유지한다.
8. 재방문·범위: 최근 검색 10개, 관심상품 100개, 저장 조건 10개를 브라우저에만 저장한다. 차단/손상/용량 초과는 검색을 중단하지 않는다. 공개 제외된 관심상품은 추적 목록에만 남고 구매 가능한 결과로 되살리지 않는다.
