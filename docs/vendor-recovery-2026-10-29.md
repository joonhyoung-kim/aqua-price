## 드림아쿠아

새 판매처 `dreamaqua.kr`의 기존 지원 분류인 술라웨시 새우 1종만 추가했다. robots+상품 2회 요청, 10초 간격, 각 15초 제한. 화면·JSON-LD 3,000원, 옵션 없음, 주 상품 판매 상태 일치를 확인했다. 숨겨진 SOLD OUT 템플릿은 품절로 해석하지 않았다. 상품 수량은 임의로 1마리라 하지 않는다.

기존 `cafe24_single_offer` 어댑터를 사용하고 판매처당 최대 2요청, 알려진 URL 1개, 자동 발견 없음으로 제한한다. 기존 판매처 배열 뒤에 추가하여 저장된 다음 판매처 ID와 기존 순서를 유지한다. 전체 실행 시간, 기존 판매처 한도, 요청 간격, 스케줄은 변경하지 않는다. 일반 배송 안내의 5,000원은 확인했으나 무료 기준·포장비·지역 추가금·합배송 조건이 미확인이라 확정 총액 정책으로 게시하지 않는다. /member/ 약관은 robots 금지 경로여서 요청하지 않았다. 방문자 수·인기 순위는 확인되지 않았다.

크랩은 미지원 분류이므로 요청/추가하지 않았다. 해리아쿠아 할인 충돌, 마린코스트 robots 차단, 동물나라 HTTPS 다운그레이드는 부모 연구 결과에 따라 보류하며 직접 접근하지 않았다.

## 데이터 게시와 검증 범위

이번 제한 표본은 기존 파서 → 메타데이터 → `applyUpdates` → `buildCatalog` 검증 경로로 반영한다. 자동 실행 기록이나 collector-status를 새로 성공한 것처럼 꾸미지 않는다. 종전 5,267개는 항목별 직렬화 내용이 모두 같고, 아쿠아가든의 복구 옵션 1개와 드림아쿠아 새우 1개를 더해 5,269개다. 확인된 품절의 공개 노출은 0개다. 원본·표본·수집기 마지막 실행 기록은 보존된다.

이전 보고의 Linux 1,400개는 main 게시 전 469 + main 게시 후 469 + preview 462의 **단계별 테스트 실행 합계**이며 서로 다른 테스트 1,400개라는 뜻이 아니다. 신규 회귀 검사는 선택 옵션의 ID/가격/선택축/재고 충돌, 신규 판매처의 예산·커서, 실패/404 보존, 품절 제외·재입고 복귀를 포함한다. 테스트 실행 결과와 운영 커밋 확인은 최종 보고에서 별도로 기록한다.
